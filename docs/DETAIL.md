**Features**

- Provider, model, balance or quota, and session spend on one line under the composer
- Picks balance, subscription quota, or cloud bill per provider, with no manual switching
- Tracks spend for this session, today, the last 30 days, and all time, stored on this machine
- Click a field to switch between full and compact layouts
- Quota credentials (Alibaba, Kimi, MiniMax, Xiaomi, Zhipu, Command Code and more) can be set right on the plugin settings page, no environment variables needed

**Announcement**: v1.24.1 may crash on update. Affected? Just tell DSH: "update dsh-bottom-info-bar to 1.24.2" to reinstall it. Sorry for the trouble!

Setup and troubleshooting: [install guide](https://github.com/songoao25/dsh-bottom-info-bar/blob/main/docs/INSTALL.md).

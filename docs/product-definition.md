# 产品定义：底部信息栏 v1.6（多服务商适配 + 分账修复）

## 一句话定位
给在 DeepSeek Harness 里使用各种 AI 服务商（DeepSeek、智谱、Kimi、OpenRouter、OpenCode Go、ChatGPT…）的个人开发者，一个**零配置、自动识别**的底部信息栏：显示当前服务商真实余额/订阅额度与实际花费——**绝不把 A 家的钱算到 B 家头上**。

## 核心场景
- 用户平时在 DSH 设置里配置了某家平台的 API 密钥（如智谱 ZAI_API_KEY），底部信息栏**自动认出**该平台并显示真实余额/订阅额度，无需在插件里做任何设置。
- 用户在同一对话中切换服务商（如 OpenCode → DeepSeek），信息栏的余额、本对话花费、今日/本月/全部花费**全部跟随当前服务商**，互不串账。
- 未适配/未配置的服务商：显示引导与降级提示，**绝不把别的服务商的余额冒充显示**。

## MVP 范围（v1.6 做）
1. **分账修复**：花费按"服务商账户"隔离聚合（本对话/今日/本月/全部）。
2. **余额跟随修复**：余额账户严格绑定当前服务商；未适配服务商不再兜底显示 DeepSeek 余额。
3. **四家零设置适配器**：智谱（zai / zai-coding-cn）、Kimi（moonshotai 系）、阶跃星辰（stepfun）、OpenRouter。
4. **未适配服务商优雅降级**：显示"未适配/未配置引导"，不崩溃、不串台。

## 明确不做（v1.6 out）
- 阿里云百炼 Token Plan 真实接入（官方无 API 密钥直查接口；排 v1.7，用官方小工具方式）
- 火山方舟/百度千帆/腾讯混元等云厂商密钥适配（需云账号 AccessKey，配置重，排后续）
- 设置页新增任何配置项（保持零配置哲学）
- 订阅令牌绑定/续期（继续由独立插件负责）

## 成功指标
- 用户在智谱配置密钥后，信息栏 60 秒内显示真实套餐等级与已用/剩余百分比，无需任何额外设置
- 切换服务商后，信息栏显示的数据与当前服务商完全一致（无串账、无串台）
- 全量测试通过（新增分账、各适配器解析、降级路径单测），零密钥落盘

# 更新通知稿（可直接发社区 / 微信群）

> **用途**：每次发布新版本后，除了写 `MEMORY.md` 复盘，还要在这里留一份**可直接复制发布**的更新通知。
> **读者是用户，不是开发者**：只讲「修了什么 bug、更新了什么功能、升到哪个版本」，**严禁**写内部实现、代码结构、审计过程、issue 编号之外的开发流水账。
> **顺序**：最新的排在最上面。
> **格式**（每期固定四段，短句、可直接粘贴到微信群 / 社区帖）：
> 1. 一句版本号 + 这次主要干了什么；
> 2. 「修好了什么」——用户能感知的现象 → 修完是什么样；
> 3. 「还改了什么」——新增 / 变化的功能（没有就写「无」）；
> 4. 「怎么升级」+ 一句实话（例如哪些场景我们没实测过，欢迎反馈）。
>
> **发给用户时只给正文**（2026-09-13 用户明确要求）：不要加「以下可直接复制发群」之类的包装说明、不要追问语气、不要用 Markdown 加粗 / 标题 / 代码块——微信群不渲染 Markdown，用户要的是选中就能直接粘贴的纯文本。因此每期正文本身也尽量少用 Markdown 语法（下面 v1.11.1 条目里的 `**` 是留档用的，发给用户时应去掉）。
>
> 注意：**不是每个小版本都值得打扰用户**。纯文案 / 文档 / 内部重构的版本可以只在 `MEMORY.md` 留档，这里写一行「本版无需对外通知」即可。

## v1.15.0（2026-09-23）

信息栏 v1.15.0 更新：修好了「两行间距偶尔莫名变大」，并把插件名、设置页文案和排版对齐了姊妹插件。

修好了什么：
1. 完整模式下，上面那行统计信息和下面那行模型/余额，中间偶尔会多出一大段空白（字还是贴着上面，但两行之间空得很明显）。现在这两行的间距被钉死了：不管窗口拉多宽多窄、明暗主题、还是来回切换完整/简洁，间距都稳定是一行的高度。
2. 信息栏的宽度以前是跟着文字长短自己伸缩的，文字一长一短，换行时机就跟着变，看起来像版式在抖。现在宽度跟上方输入框的内容宽度对齐，稳定不抖，窄窗口下也不会溢出。
3. 设置页在少数情况下会整块空白，只剩宿主渲染的标题和描述。原因是读取界面语言那一步一旦出错，整块配置区就渲染中断；现在这条链路每一步都有兜底，读不到就跟随浏览器语言、最差也是英文，不会白屏。
4. 设置页的错误提示以前靠「比对宿主文案」来翻译，宿主改一次文案就可能中英混排；现在每个错误都带固定编号，提示语按编号取当前语言。

还改了什么：
1. 插件在插件列表和详情页里的名字以前显示成包名 dsh-bottom-info-bar，现在是「底部信息栏 / Bottom Info Bar」，中英文界面各显示对应语言。
2. 设置页排版收紧：区块间距从 24px 改成和宿主一致的 12px，列表首行/末行不再多出上下留白，顺手删掉几条没用的样式。

怎么升级：点信息栏上的红色「新版本提醒」标签复制命令，粘到终端执行，然后重启 dsh web——这次必须重启，挂载行的 id 变了（dsh-bottom-info-bar → bottom-info-bar）。如果你在 profile 的 cordis.patch.yml 里覆盖过这个插件，请把覆盖行的 id 一起改成 bottom-info-bar（name 仍写包名），否则覆盖会静默失效。1.14.x 的用户升级到 1.15.0 即可。

一句实话：中英两种界面下逐页核对过（设置页各状态、信息栏三种模式、完整/简洁两态），英文界面里没有中文残留；插件标题/描述也用宿主的解析函数实读确认过双语齐备。

信息栏 v1.14.3 更新：修好了「点了更新提醒、更新命令也执行了，插件却没有真的更新」的问题。

修好了什么：
1. 用本地代码（git 仓库 / 一键脚本）方式安装时，以前复制出来的更新命令会因为你当前的分支没有推到远端而直接失败。现在命令会自动切到仓库的默认分支，再用「只快进」的方式更新；有未提交的改动或本地提交时，git 会明确拒绝，不会覆盖你的东西。
2. 同一种安装方式下，更新完还会自动重新构建插件产物。以前只更新代码不重建，重启 DSH 后跑的还是旧版本——看起来就像「更新了但没生效」。
3. 更新完成后，红色「有新版本」提醒刷新页面就会消失，不用再等到重启。

还改了什么：
无。

怎么升级：点信息栏上的红色「新版本提醒」标签复制命令，粘到终端执行，然后重启 dsh web。已经是 1.14.2 的用户升级到 1.14.3 即可。

一句实话：这次修的正是「更新命令本身」，已在真实的本地代码安装场景下逐条验证（拉代码 → 切默认分支 → 快进 → 重建产物）；桌面版与 Windows 组合没有在本轮实测，遇到问题欢迎反馈。

## v1.13.0（2026-09-18）

信息栏 v1.13.0 更新：适配 DSH 新版插件管理页，装上和卸下都更干净了。

2. 卸载之后不留残留：样式、界面元素、后台的定时刷新、网络接口全都跟着一起撤掉，DeepSeek 原生的统计栏和上下文圆环会恢复原样。

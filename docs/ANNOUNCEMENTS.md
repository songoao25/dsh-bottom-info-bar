# 更新通知稿（可直接发社区 / 微信群）

> **用途**：每次发布新版本后，除了写 `MEMORY.md` 复盘，还要在这里留一份**可直接复制发布**的更新通知。
> **读者是用户，不是开发者**：只讲「修了什么 bug、更新了什么功能、升到哪个版本」，**严禁**写内部实现、代码结构、审计过程、issue 编号之外的开发流水账。
> **顺序**：最新的排在最上面。
> **格式**（每期固定四段，短句、可直接粘贴到微信群 / 社区帖）：
> 1. 一句版本号 + 这次主要干了什么；
> 2. 「修好了什么」——用户能感知的现象 → 修完是什么样；
> 3. 「还改了什么」——新增 / 变化的功能（没有就写「无」）；
> 4. 「怎么升级」+ 一句实话（例如哪些场景我们没实测过，欢迎反馈）。
>
> **发给用户时只给正文**（2026-09-13 用户明确要求）：不要加「以下可直接复制发群」之类的包装说明、不要追问语气、不要用 Markdown 加粗 / 标题 / 代码块——微信群不渲染 Markdown，用户要的是选中就能直接粘贴的纯文本。因此每期正文本身也尽量少用 Markdown 语法（下面 v1.11.1 条目里的 `**` 是留档用的，发给用户时应去掉）。
>
> 注意：**不是每个小版本都值得打扰用户**。纯文案 / 文档 / 内部重构的版本可以只在 `MEMORY.md` 留档，这里写一行「本版无需对外通知」即可。

## v1.14.0（2026-09-19）

信息栏 v1.14.0 更新：现在支持显示 Command Code 的订阅额度。

修好了什么：
1. 以前即使识别到 Command Code，也只能显示供应商名称，看不到额度。现在可以显示 5 小时窗口和每周窗口。
2. 已知套餐可以显示月度 credits、月度重置时间，以及月度、购买和免费 credits 的合计剩余量。
3. credits 会按 credits 显示，不会误当成人民币余额；未知套餐或接口返回异常时不会乱算额度，也不会悄悄覆盖上一次正常数据。

还改了什么：
1. 支持 `command`，同时兼容 `command-code` 这个旧别名。
2. 可以读取 Command Code CLI 的本地登录态，也可以使用 `COMMAND_CODE_API_KEY` 或 `CMD_API_KEY`。

怎么升级：升级到 v1.14.0 即可。

一句实话：这次已完成官方接口适配、解析测试、凭据和失败场景测试，并已发布到 npm；我们这边没有真实 Command Code 账号做在线额度验证。如果你实际使用时遇到官方返回字段差异，欢迎继续反馈。

## v1.13.0（2026-09-18）

信息栏 v1.13.0 更新：适配 DSH 新版插件管理页，装上和卸下都更干净了。

修好了什么：
1. 新版插件管理页里，现在能直接在这个插件自己的页面上改配置（显示哪些信息、各自的配色、信息密度），不用再去设置页里翻。
2. 卸载之后不留残留：样式、界面元素、后台的定时刷新、网络接口全都跟着一起撤掉，DeepSeek 原生的统计栏和上下文圆环会恢复原样。
3. 复制内容时如果出了岔子，以前会在页面上留下一个看不见的残留节点，现在不会了。

还改了什么（这一条请留意）：
1. 从插件管理页卸载这个插件时，会一并清空累计花费记录和字段设置——卸载即清空，不可恢复。只是「停用」那一排、或者正常重启 DeepSeek Harness，数据一个字都不会动。
2. 为了账单安全，只有在能明确确认「真的卸载了」的时候才会清。只要有任何判定不了的情况（读不到配置、目录被改到别处等等），一律保留数据不动。

怎么升级：升级到 v1.13.0 即可。

一句实话：这次的卸载逻辑已经用 16 条自动化用例覆盖（各种「判定不了」的分支都验证为保留数据）；但如果是关掉 DSH 之后再用别的方式卸载，清理不会触发，数据会留在磁盘上，需要手动删除 ~/.dsh/dsh-bottom-info-bar 目录。

怎么升级：升级到 v1.12.0 即可。

一句实话：这次已在本机 DSH 0.1.6-alpha.2 的网页环境刷新验证通过；桌面版和 Windows 组合没有在本轮实测，遇到问题欢迎反馈。

## v1.11.1（2026-09-13）

以下为可直接粘贴的纯文本正文（微信群不渲染 Markdown，故不使用任何 Markdown 标记）：

信息栏 v1.11.1 更新：主要修好了智谱 Coding Plan 看不到额度的问题。

修好了什么：
1. 有用智谱 GLM Coding Plan 的朋友反馈，底条上套餐名旁边完全不显示额度窗口。原因是智谱 7 月底把套餐改成了积分制，接口返回的字段名变了，插件没认出来。现在能正常读了。
2. 顺手修好一个更早就存在的问题：每周额度窗口一直没显示过（不只是积分制用户，老套餐用户也一样）。现在 5 小时窗口和周窗口都会显示。
3. 如果遇到「只有套餐名、没有任何窗口、也没有报错」这种哑掉的状态，现在会显示「刷新失败」并保留上一次的数据，不会再悄悄变空。
4. 重置时间拿不到的时候，简洁模式不再整块消失。

还改了什么：
1. 智谱的 MCP 月度额度（联网搜索、网页读取、Zread 这些工具调用）现在也会显示成月窗口。
2. 用量很低时，剩余百分比不再因为上游取整而错误地显示成 100%。

怎么升级：升级到 v1.11.1 即可。信息栏里出现红色「有新版本」时，点一下会复制更新命令。

一句实话：智谱套餐我们这边没有订阅，这次是拿用户反馈的真实数据加官方文档对出来的，真机效果还需要用智谱的朋友帮忙确认；国内站（open.bigmodel.cn）是否同样返回新格式也还没实测。有问题欢迎在 issue 里说一声。

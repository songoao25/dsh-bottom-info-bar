# 更新通知稿（可直接发社区 / 微信群）

> **用途**：每次发布新版本后，除了写 `MEMORY.md` 复盘，还要在这里留一份**可直接复制发布**的更新通知。
> **读者是用户，不是开发者**：只讲「修了什么 bug、更新了什么功能、升到哪个版本」，**严禁**写内部实现、代码结构、审计过程、issue 编号之外的开发流水账。
> **顺序**：最新的排在最上面。
> **格式**（每期固定四段，短句、可直接粘贴到微信群 / 社区帖）：
> 1. 一句版本号 + 这次主要干了什么；
> 2. 「修好了什么」——用户能感知的现象 → 修完是什么样；
> 3. 「还改了什么」——新增 / 变化的功能（没有就写「无」）；
> 4. 「怎么升级」+ 一句实话（例如哪些场景我们没实测过，欢迎反馈）。
>
> 注意：**不是每个小版本都值得打扰用户**。纯文案 / 文档 / 内部重构的版本可以只在 `MEMORY.md` 留档，这里写一行「本版无需对外通知」即可。

## v1.11.1（2026-09-13）

**这次主要修好了「智谱 Coding Plan 看不到额度」的问题。**

修好了什么：

- 有用智谱 GLM Coding Plan 的朋友反馈，底条上套餐名旁边**完全不显示额度窗口**。原因是智谱 7 月底把套餐改成了积分制，接口返回的字段名变了，插件没认出来。现在能正常读了。
- 顺手修好一个更早就存在的问题：**每周额度窗口一直没显示过**（不只是积分制用户，老套餐用户也一样），现在 5 小时和周窗口都会显示。
- 之前如果遇到「只有套餐名、没有任何窗口、也没有报错」这种哑掉的状态，现在会显示「刷新失败」并**保留上一次的数据**，不会再悄悄变空。
- 重置时间拿不到的时候，简洁模式不再整块消失。

还改了什么：

- 智谱的 **MCP 月度额度**（联网搜索 / 网页读取 / Zread 这些工具调用）现在也会显示成月窗口。
- 久用低额度时，剩余百分比不再因为上游取整而错误地显示成 100%。

怎么升级：升级到 **v1.11.1** 即可。信息栏里出现红色「有新版本」时点一下会复制更新命令。

一句实话：智谱套餐我们这边没有订阅，这次是拿用户反馈的真实数据 + 官方文档对出来的，**真机效果还需要用智谱的朋友帮忙确认**；国内站（open.bigmodel.cn）是否同样返回新格式也还没实测。有问题欢迎在 issue 里说一声。

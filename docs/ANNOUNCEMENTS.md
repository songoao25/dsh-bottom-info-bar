# 更新通知稿（可直接发社区 / 微信群）

> **用途**：每次发布新版本后，除了写 `MEMORY.md` 复盘，还要在这里留一份**可直接复制发布**的更新通知。
> **读者是用户，不是开发者**：只讲「修了什么 bug、更新了什么功能、升到哪个版本」，**严禁**写内部实现、代码结构、审计过程、issue 编号之外的开发流水账。
> **顺序**：最新的排在最上面。
> **格式**（每期固定四段，短句、可直接粘贴到微信群 / 社区帖）：
> 1. 一句版本号 + 这次主要干了什么；
> 2. 「修好了什么」——用户能感知的现象 → 修完是什么样；
> 3. 「还改了什么」——新增 / 变化的功能（没有就写「无」）；
> 4. 「怎么升级」+ 一句实话（例如哪些场景我们没实测过，欢迎反馈）。
>
> **发给用户时只给正文**（2026-09-13 用户明确要求）：不要加「以下可直接复制发群」之类的包装说明、不要追问语气、不要用 Markdown 加粗 / 标题 / 代码块——微信群不渲染 Markdown，用户要的是选中就能直接粘贴的纯文本。因此每期正文本身也尽量少用 Markdown 语法（下面 v1.11.1 条目里的 `**` 是留档用的，发给用户时应去掉）。
>
> 注意：**不是每个小版本都值得打扰用户**。纯文案 / 文档 / 内部重构的版本可以只在 `MEMORY.md` 留档，这里写一行「本版无需对外通知」即可。

## v1.20.0（2026-09-26）

信息栏 v1.20.0 更新：设置页理清了，更新按钮不再「点一下就装好」。建议所有在用的人都升到这一版。

修好了什么：

1. 「检查更新」以前点了会直接下载安装，按钮名字和它干的事对不上。现在它只检查——查到新版本会告诉你查到的是哪一版，装不装由你按旁边的按钮决定。全自动更新没变，还是查一次、查到就装，装好提示你重启应用。
2. ChatGPT 订阅模式下，模型那一栏永远不跟着你选的模型变。现在正常显示了，套餐名挪到鼠标悬停时才出现。
3. 桌面端用内置 DeepSeek 账号（设置 → 账户里登录的那种）时，服务商那一栏显示「未适配」、没有余额。现在会正常显示账号余额，和填 API Key 时是同一个数。
4. 点完更新相关按钮后，设置页会自己跳到最顶端。现在不会了。
5. 顺带修了版式：能一行放下的时候不再折行；字号跟随你的 DSH 字号设置走，不再和旁边那行不一致；设置页里几个按钮以前一高一低，现在对齐了。

还改了什么：

1. 设置页里「插件信息」以前是一长串，分不清哪条跟哪条是一类。现在按用途分成五块，每块有一句说明：账号与身份、余额相关、订阅相关、计费与花费、通行项（自定义文字、时间这类）。字段本身一个没少，你原来的开关和顺序都还在。
2. 每块的小标题下面写了这块是干什么的，看一遍就知道该去哪个块里找了。

怎么升级：升到 v1.20.0，装好后重启一次 DSH。已经装在 v1.19.0 及以上的，也可以不管它——全自动更新会自己下好，你找个时间重启即可。

一句实话：桌面端内置账号那条余额我们只在 macOS 的桌面端真机验证过，网页端没有这个服务，会显示成正常的降级文案。如果你那边显示对不上，欢迎回帖反馈。

## v1.19.3（2026-09-25）

信息栏 v1.19.3 更新：把设置页里「版本与更新」那一块重新理了一遍，顺手修掉两个按钮的毛病。装的是 v1.19.0 之后的版本，建议升到这一版。

2. 「手动更新」方式下点「检查更新」，会把同一个版本反复下载一遍。现在不会了。

还改了什么：

1. 那一块重新排成了从上往下三层，一眼能看懂。最上面是「现在什么情况」：一句结论，下面一行小字写着运行中的版本、最新版本，以及「上次检查」是什么时候。中间是这一块唯一要你选的东西：更新方式（全自动更新 / 手动更新），说明文字跟着你的选择变，不再两条并排堆在一起。最下面是「出问题时的办法」，平时不出现。

3. 「检查更新」按钮只在选手动更新时出现。选全自动的时候，它本来就在做已经做完的事，点了反而会重新下载一遍。
4. 更新失败的原因改成说人话。以前会直接甩一行英文报错给你，现在写的是「更新包没下完整（网络中途断了），这次已放弃，你现在用的版本没受影响」这类。详细报错仍留了一份日志，在 ~/.dsh/dsh-bottom-info-bar/update-log.jsonl。
5. 如果自动更新在当前环境用不了（比如插件是从源码副本或链接装进来的），那一块不再摆出用不了的按钮，只说明原因。

顺便订正一处之前写错的说明：文档里说过「启动时查一次，之后最多每 15 分钟复查一次」，这是错的。检查只在启动时做一次；15 分钟那个是设置页刷新界面数字用的，不会触发下载。之所以够用：新版本本来就必须要重启才生效，而重启本身就会触发下一次检查。

怎么升级：升到 v1.19.3，装好后重启一次 DSH。到这一版为止，「全自动更新」已经能用了：以后有新版本它会自己下载好，提示你重启一次即可。

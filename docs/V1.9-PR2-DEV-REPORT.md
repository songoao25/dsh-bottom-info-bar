## 设计偏差（记录在案）

1. 注册表 host 侧走 ESM import 而非构建注入（消除 src/lib 白名单漂移；客户端仍锚点注入）。
2. balanceError 合并「余额获取失败/余额刷新失败」两个同义分支为一个开关。
3. 锚点按三态拆 3 个 id，恒开+双重兜底。
4. 状态色保持语义：自定义颜色只作用于字段基础文字，「低」/警示/错误标签保留语义色。
5. 自定义 hex 同时注入 -dark 变体（向白混合 45%）。
6. writeFileAtomic 模块级独立实现（同型 tmp+fsync+rename），暴露 __settingsInternals 供单测。
7. 重置按钮用直接生效而非乐观更新；逐字段开关/改色用乐观+回退。
8. 设置页与信息栏同一 bundle 拼接（插件客户端入口唯一），bibSet*/InfoBarSettings* 前缀隔离命名。
